## 🧠 Featured Project

**[Deep Learning Breast Cancer Classification](https://github.com/peter-kautwima/DeepLearning-BreastCancer-Classification)** — BSc Final Project, University of London (2026)

End-to-end deep learning pipeline for malignant/benign mammogram classification on the CBIS-DDSM clinical dataset. Best model: **AUC 0.7678** — exceeding the mean individual radiologist AUC benchmark (McKinney et al. 2020). Implemented Grad-CAM explainability via a custom GradientTape workaround for a Keras 3 graph disconnection issue.

`Python` `TensorFlow/Keras` `Grad-CAM` `Transfer Learning` `CNNs` `Google Colab`
